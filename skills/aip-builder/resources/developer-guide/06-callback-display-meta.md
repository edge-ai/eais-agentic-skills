### 3.4. Display Meta function

Draw shapes (text, rectangles, circles, lines, arrows) by returning structures via `set_new_display_meta()`.

Shape drawing is supported in Callback. Users can draw text, rectangles, circles, lines and arrows at any position for each input source.

Drawing shapes is done by writing data to a structure called DisplayMeta defined by NVIDIA. For more information on this structure, see the [official documentation](https://docs.nvidia.com/metropolis/deepstream/dev-guide/text/DS_plugin_metadata.html).

Dedicated functions can be implemented for additional drawing of arbitrary shapes in Callback. The name of this function is `set_new_display_meta()` and is executed after `parse_batch_meta()`. (i.e. this is a function that is executed every frame).

If additional drawing of shapes is not required, the AIP developer does not have to implement this function.

Two arguments are passed to this function:

- `frame_data`: the output returned by `parse_batch_meta()` is passed directly to this function.
- `get_new_display_meta`: a function to generate an empty DisplayMeta structure is provided via an argument. The information required for drawing should be written to the structure generated by this function.

This function has one return value:

- `display_meta_dict`: a dictionary with int keys and a list of DisplayMeta values. The key should be the ID of the input source to which the DisplayMeta is applied.

Note that a single DisplayMeta structure can only hold a maximum of 16 items for each shape. If you want to draw more than that (e.g. 20 rectangles), you must generate multiple DisplayMeta structures and return them as a list.

#### Code example

```python
def set_new_display_meta(self, frame_data: Any, get_new_display_meta: Callable) -> Dict[int, List[NvDsDisplayMeta]]:
    display_meta_dict = {}

    for idx, frame in enumerate(frame_data):
        meta_list = []

        # Draw text
        display_meta = get_new_display_meta()
        display_meta.num_labels = 1
        source_id = frame['source_id']
        objects = frame['num_obj_meta']
        py_nvosd_text_params = display_meta.text_params[0]
        py_nvosd_text_params.display_text = f"cam{source_id+1}: {self.to_int(objects)} objects detected"
        py_nvosd_text_params.x_offset = 10
        py_nvosd_text_params.y_offset = 20
        py_nvosd_text_params.font_params.font_name = "Serif"
        py_nvosd_text_params.font_params.font_size = 30
        py_nvosd_text_params.font_params.font_color.set(0, 1, 1, 1)
        py_nvosd_text_params.set_bg_clr = 1
        py_nvosd_text_params.text_bg_clr.set(1, 0, 0, 1)
        meta_list.append(display_meta)

        # Draw a circle in the centre of all detected objects
        if source_id in self.obj_coords_dict:
            counter = 0
            display_meta_circle = get_new_display_meta()
            for coords in self.obj_coords_dict[source_id]:
                circle_params = display_meta_circle.circle_params[counter]
                circle_params.xc = self.to_int(coords[0])
                circle_params.yc = self.to_int(coords[1])
                circle_params.radius = 25
                circle_params.has_bg_color = True
                if coords[2] == 0:
                    circle_params.circle_color.set(0, 1, 0.5, 1)
                    circle_params.bg_color.set(0, 0, 1, 1)
                elif coords[2] == 1:
                    circle_params.circle_color.set(0, 0.5, 1, 1)
                    circle_params.bg_color.set(0, 1, 0, 1)
                else:
                    circle_params.circle_color.set(0.5, 0, 1, 1)
                    circle_params.bg_color.set(1, 0, 0, 1)

                counter += 1
                if counter == 15:
                    display_meta_circle.num_circles = counter
                    meta_list.append(display_meta_circle)

                    counter = 0
                    display_meta_circle = get_new_display_meta()

            if counter != 15:
                display_meta_circle.num_circles = counter
                meta_list.append(display_meta_circle)

        display_meta_dict[source_id] = meta_list

    return display_meta_dict
```
